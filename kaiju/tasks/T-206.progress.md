# T-206 destruction camera for the demo record mode

Done: `SliceBootstrap` `-sliceRecordDestructionCam 1` (default OFF; no effect without `-sliceRecord`). At each scripted impact the camera cuts (ThirdPersonRig scripted pose + Cut, same integer-scale pixel pipeline as the smoke's destroy view) 1.6 s before the hit to a side-on pose 190-310 m from the target, ~20 deg down, line-of-sight checked; holds 3 s after the hit; then ClearScriptedPose + Cut back to follow. Cut and return are logged in record.json `scripted_events`.
Default gameplay, default record output and the build output without the flag are unchanged. The flag is a command-line arg (like the other -sliceRecord* args), not a FeatureFlags json.
Verified: build.sh --no-smoke OK; 26 s player record at 1920x1080 with the flag; frames in /tmp/kaiju-build/t206/rec, contact sheet evidence/T-206/contact_sheet.png.
Not verified: full 100 s run (only the first impact t=12 s), pixel-grid check on the cut frames, EditMode tests (no asmdef/scene change).
Frames: sphere visible at f490 (t=16.3 s), target box removed by f525; framing is wide and low-contrast, tuning (closer/higher) is follow-up.
