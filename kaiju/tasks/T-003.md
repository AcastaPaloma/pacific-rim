## Linked research and contracts (binding)
`research/R-004.md`: products and endpoints per layer, the projection and world origin, vertical datum, the `geo_tile@v1` data spec, the recommended M0 tile bounds, the landmark table, and `M-005@v1`.

## Scope
1. `Pipelines/geo/` (Python, kaiju conda env): one fetch script per layer and a bake step producing `geo_tile@v1` for the M0 tile recommended by R-004. Raw downloads in `Pipelines/geo/cache/` (git-ignored); baked tile data committed (LFS for large rasters) under the path the spec gives; a manifest with source, licence, attribution text, fetch date and checksum per layer. Re-running is deterministic and idempotent. `pytest` tests for projection maths, tile indexing, ID determinism and manifest completeness.
2. `World.Geo.Contracts` + `World.Geo` (Unity): `IGeoLayer` importers for terrain+bathymetry (one continuous surface across the shoreline), buildings (extruded footprints with real heights and stable IDs), roads, faults, and a sea-level water plane; a tile builder that assembles a tile in a scene through Editor/runtime API (never text-edited scenes). Geometry must survive the pixel pipeline: clean silhouettes, no z-fighting, flat-shadeable.
3. An attribution asset listing every layer's required credit (OSM ODbL credit is mandatory).
4. Measurement hooks for `M-005@v1`: an export of built-world facts (landmark positions and heights as built, building height list, sampled terrain/bathymetry at control points, tile statistics) that the metric procedure can check against independent sources, and skyline captures from the R-004 viewpoints inside this tile.
5. Feature flags (default off), config under `Assets/Game/Config/`, EditMode tests, `MODULE.md` for World.Geo and a README for Pipelines/geo.

## Constraints
- `MODULARITY.md` §5 recipe in order; World.Geo is L2 and references only Core contracts and its own.
- 1:1 scale in metres in the R-004 coordinate system; no vertical exaggeration; no invented buildings. Missing heights are filled only by the documented fallback rule from R-004 and flagged per building.
- Respect licences exactly; a layer whose licence is unclear for a commercial game is not shipped: record a `Q-###` and use the fallback.
- Keep the tile within the M-008 budget proposed in R-003/R-004 (triangles, draw calls, memory); report the numbers.
