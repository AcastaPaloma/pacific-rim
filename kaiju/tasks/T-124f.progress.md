## Changes (all bit-identical; defaults and thresholds untouched)
- `Geo/GeoBufferPool<T>`: tiny thread-safe pool (at most 3 buffers per type, exact length, >= 65536 elements). Rent(clear) returns zeroed arrays, so results equal fresh arrays.
- `RtinMesher.Build`: errors lattice and mask pooled; new optional `keepRenderHeights` (default true = old behaviour, RenderHeights returned); false builds the lattice in a pooled buffer and returns null (metrics identical); struct stack items; unrolled normal accumulation (same order); one Dictionary/List reused across chunks.
- `PngGray8.Decode`: sized buffers instead of growing MemoryStreams (25 MB -> 8.4 MB for the 2048 water mask); same pixels.
- `GeoHeightField.DecodeR16` (FromR16 uses it) and `GeoLodTileReader.Terrain`: r16 bytes and decoded heights from the pool, returned after meshing; `KeepTerrainHeights` keeps the old behaviour (the lattice is then a fresh array handed to the caller).
## Proof of bit-identity (`TileBuildEqualityTests`, golden hashes taken from the pre-change code at commit ac63335)
SHA-256 over every array of every mesh (positions, normals, uvs, indices, chunk ids, names), RTIN render heights and error metrics, byte costs: RTIN synthetic field with and without forced edges; repeated builds on one thread (no state leaks through the pool); synthetic geo_lod tile (default and KeepTerrainHeights); committed L0 tile 30_36 (render, physics chunks 3_3 and 5_2); the real baked L1 17_17, L2 8_8, L3 4_4, L4 2_2 tiles (pre-change hashes in `evidence/T-124f/real_golden_before.txt`, compared via KAIJU_T124F_REAL_GOLDEN): all equal after the change.
