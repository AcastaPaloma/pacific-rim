# T-124g: real-pyramid tests no longer assume the first L1 tile has buildings

## Change (test code only, `Assets/Game/World/Streaming/Host/Tests/EditMode/GeoLodReaderTests.cs`)
- `RealBakedTilesValidateAndMatchTheirManifests`: per level, takes the first two sorted tiles whose manifest `stats.building_triangles > 0` (new helper `HasBuildingTriangles`) instead of the first two sorted tiles (which start with ocean tiles that have no buildings, so the winding check's `Assert.Greater(total, 0)` failed). All assertions and tolerances unchanged.

Same removal assertion; Assert.Ignore only if no L1 tile has such a building.
- No product code, thresholds or tolerances touched.
