# T-190: Physical audio, design spec and task plan (T-190..T-199)

Feature F-070 (proposed, R-132 section 12), supports F-009 / M-009. Research: `research/R-132.md`. Module: `Assets/Game/Audio` (`MODULE.md`). Flag `audio.physical`, default off. Status of T-190: engine-free contract and maths DONE (59 NUnit tests, `evidence/T-190/dotnet-test.log`). T-191..T-199 are queued.

## 1. Design spec (summary)
Pipeline per event: producer event (bus) -> `AudioEvent` (adapter) -> `AudioPlanner.Plan` (distance, ISO 9613-1 low-pass, delay, Doppler, pan/ITD, SPL, score) -> `VoiceAllocator` (budget, steal) -> `IAudioSink.Play(VoiceCommand)` -> modal / noise / granular synth -> mixer -> `Limiter`. Everything before the sink is pure and engine-free; the Unity part is only an adapter. Sounds start at the contact step (M-009) plus physical delay.

### Producer events consumed (real type names, by module)
| Source | Event type (namespace) | Fields used | AudioEventKind |
|---|---|---|---|
| Physics.Body | `FootContact` (Game.Physics.Body) | Unit, Foot, Step, ContactId, Position, VerticalImpulseNs, NormalForceN, ApproachVelocity | FootContact (energy from impulse^2 / (2 m_eff) or from approach KE) |
| Physics.Body | `FootLoaded` | PeakNormalForceN, ImpulseNs, WindowSeconds | refines FootContact gain |
| Physics.Body | `FootLiftOff` | ContactId | Wade end / mud suck |
| Combat | `WeaponFired` | Source, Weapon, Step, Muzzle, Dir, ProjectileMassKg | MuzzleBlast, then ProjectileWhistle / SupersonicCrack |
| Combat | `RecoilImpulse` | ImpulseXYZ, Point | MuzzleBlast low thump |
| Combat | `ImpactImpulse` | TargetKind, Building, Point, ImpulseNs, EnergyJ | Impact |
| Destruction | `BuildingDamaged` | BuildingId, State, PrevState, EnergyJ, Cause, DebrisKg | StructureFailure, DebrisRain |
| Seismic | `QuakeBegan`, `FaultRupture`, `EmergencePoint`, `IShakingField` | Mw, OriginTimeS, Hypo*, FaultId, PgaG | QuakeP, QuakeS, QuakeRumble |
Positions are world metres (`Vector3` in Body, doubles in Combat); the adapter converts. Events keep their `Step`; the adapter maps step to the audio DSP clock (offset = sim step time minus audio DSP time at frame start).

### Contracts (done, `Game.Audio.Contracts`)
`AudioEvent`, `AudioEventKind`, `AudioMaterial`, `AudioSurface`, `Listener`, `VoiceCommand`, `IAudioEmitter`, `IAudioSink`, `IAudioMixer`, `AudioProfile`, `AudioFlags`, `AudioContractVersions`.

### Runtime (done, `Game.Audio`)
`AudioMath`, `ModalSynth`, `VoiceAllocator`, `Limiter`, `AudioPlanner`.

### Decisions
Procedural first; samples later (Q-265 yes, original only). No HRTF in v1 (Q-266). Listener = camera focus pulled 25 percent to the player (Q-267). Physical delay always on (Q-268). Audio is a presentation consumer with replayable decisions (Q-269). All decided autonomously (founder asleep).
