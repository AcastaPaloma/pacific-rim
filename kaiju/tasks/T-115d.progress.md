## New finding: C2 is not translation invariant (explains 0.4658 -> 0.0109)
Moving only the hunt spawn (pure land, no field) changes the `nofocus@1` control wildly: mean_ff_nofocus 0.868 (spawn 6000,2000), 1.000 (+30 km x), 0.696 (+60 km x), 0.968 (+100 km x), 0.995 (+100 km y), while the candidate stays at 0.99995 (20 seeds x LLMH,LMHH; diagnostic `--hunt-shift`, flat map). So `fe_vs_nofocus` swings 0..1 with the absolute position (float32 rounding at 10^4..10^5 m perturbs the chaotic nofocus trajectories) and C2 at 0.4658 (T-115b/c) and 0.0109 (real) are the same blocker: the control arm's noise, not the candidate. Needed before any C2 verdict: run the harness in a local frame (subtract the scenario origin) or `double` positions, and a nofocus sample large enough (or paired) to be stable. Routed as a research item for the lead; no clause touched.
