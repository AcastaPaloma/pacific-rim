## Scope (M0)
1. `Core.Contracts` assembly (engine-free): event bus interface, service registry interface, ID value types, feature-flag interface, simulation clock interface, save-store interface. Version any data spec.
2. `Core` assembly (engine-free where possible): implementations of the above.
   - Event bus: typed struct events, subscribe/unsubscribe, deterministic dispatch order, same-step delivery, safe re-entrancy (publish and unsubscribe from inside a handler), a failing handler does not stop the others, zero managed allocation per publish in steady state.
   - Service registry: register/resolve by contract type, explicit failure on missing or duplicate registration, no static singletons that survive a test.
   - IDs: stable value-type IDs for entities, building IDs (F-043), player slots (D-004), deterministic and serialisable. Nothing assumes a count.
   - Feature flags: loaded from `Assets/Game/Config/FeatureFlags` (JSON or ScriptableObject backed by an engine-free model); unknown flag reads as **off**; new features default off (Rule 5).
   - Clock: fixed simulation step in seconds exposed to engine-free code (STACK: "a fixed physics step").
   - Save: versioned save-store contract with one simple implementation (JSON file) sufficient to round-trip ID-keyed records; no gameplay data yet.
3. Thin Unity adapter (the only engine-dependent part): bootstrapping the registry and loading flags/config in the editor and player.
4. Tests: one NUnit test source run by both `dotnet test` (engine-free, from `DotnetTests/`) and Unity EditMode (`Assets/Game/Core/Tests/EditMode`). An allocation test for the bus. `.gitignore` currently ignores `*.csproj`/`*.sln`: add a narrow exception for `DotnetTests/`.
5. `Assets/Game/Core/MODULE.md` from the `MODULARITY.md` §6 template.
