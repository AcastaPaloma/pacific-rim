# T-197b collapse flash / impact dust legibility (unlit/emissive)
Done
- PixelDestructionFx materials are now EMISSIVE: base colour black, _EMISSION = the palette-ramp colour (gain 1, so it stays on the ramp), no smoothness/metallic/env reflections. Lighting, shading and exposure add nothing; the colour entering haze + quantise is exactly the ramp entry. Previously Lit colours x2.6 / x1.25 were multiplied by light and quantised to a mid tone (T-207: "flash does not read").
- Colours = haze-ramp entries picked for luminance contrast vs the mid-ramp (typical background) with Maths/DestructionFxLook.PickContrasting (min ratio 1.6); embers = profile accent. No palette, ramp or threshold change; no new asset/shader (Lit shader + emission keyword; no Shader.Find).
- Pure logic Rendering/Pixel/Maths/DestructionFxLook.cs (Luma, Contrast, FlashPhase, PickContrasting, EmissionGain) + Tests/EditMode/DestructionFxLookTests.cs: 8 tests, pass under dotnet (net11 roll-forward scratch project; same sources as the Unity test asmdef).
- evidence/T-197b/measure_legibility.py: per burst, flash window (b+1..b+4) and dust window (b+5..b+40): changed share, mean |dLuma|, region-vs-ring contrast ratio on the burst frame and on the pre frame.
