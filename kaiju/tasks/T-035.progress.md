### Definitions I chose (R-006 §2 and §1 were out of my reading list)
- Default share unit: one structure per `part_of` group; area = root outline area; source = `height_source` of the tallest element (base + height_m); structures with `excluded` set are dropped (the bake's recorded exclusions only; v1.1's OSM-tag/water exclusions are not re-derived, so the union share is an upper bound on what the R-006 §2 chain would count). Count and perimeter shares are not yet reported (R-020 asks for them reported).
- Seam |dE|: difference of the shared edge nodes (tile A last column/row vs tile B first), built surface = `terrain.r16` decoded, whole edge (a superset of "band + 5 m"). The source-step "excess" of R-006 §1 needs the 3DEP/CUDEM cache and is not computed.
- Vertex gap: horizontal distance between the nodes of both tiles from each manifest's `bounds_baytm` and sample count, float64. Vertical differences are in |dE|.
- Clipped area and ownership: baked footprints are unclipped (owner = tile containing point_on_surface), so "clipped" is simulated: each footprint clipped to each tile square of the list, sum of pieces vs area inside the union. This is near-vacuous on baked data; real piece data from the Unity build must be fed in step 2 for it to bite. Collider overlap uses unclipped render footprints (remainder geometry for structures with parts) of different owner tiles, skipping same-structure pairs.
