# T-004 fix cycle 2: M-003 c1/c2 regression

## Root cause
Two tuning effects, no code cause. (1) With the flat value-ladder rungs the haze lift per depth band was too slow
(hazeFullM 10750/12000 m), so scene-value differences between ground and form faces outweighed the haze and band means
dipped by 3-5 L* (c1); the dip sat at the same bands regardless of ladder step, so it was scene content, not rung snapping.
(2) Coarse rungs (ladderMinStepL 4.5) shifted flat-region means by up to half a rung, which broke the c2 pair-mean at
slate_crimson. A finer ladder weakened DIG, so ditherSpread was raised to compensate.

## Change (PaletteProfileTuning.json only)
- defaults: ladderMinStepL 4.5 -> 2.5, ditherSpread 0.6 -> 0.9
- hazeFullM: 10750 -> 6500 (rust, teal), 12000 -> 7200 (amber, lavender, crimson)
- slate_crimson: ladderMinStepL 3.0, ditherSpread 1.2 (ladderTopL 50 kept)
