## Spec defects and questions for the scribe (proposed; defaults in use, marked Assumed)
- **Q-NEW-a (style_capture@v1.1):** the contract does not say where the haze_cal dark / light pairs are. Default
  (Assumed): sidecar `haze_targets: [{distance_m, dark_px, light_px}]` in internal pixels. Also add sequence.json
  `viewpoint` for M-004 grouping, and say whether EXR depth must be supported (tool v1 reads png16_log only).
- **Q-NEW-b (M-003 c2):** "pair mean L\* non-decreasing" has no allowance in the text but R-002's script used -2.0.
  Default (Assumed): 0.0 as written (registry `meanL_drop_allowance`).
- **Q-NEW-c (M-003 b window semantics):** "inside interleaved windows" is ambiguous; the window anchored at the pixel
  (R-002's implementation) reproduces the validation table, "any covering window" (expect-A §4.8) does not. Default:
  anchored window.
- **Q-NEW-d (M-001.8 / M-001.5 / M-001.9 scaling):** the table gives fixed values; procedure 4 says limits come from
  header values. Default (Assumed): 0.085 g scaled by header (W_f/2)/h, 4.0 deg/s^2 scaled by 42.4/l.
- **Q-NEW-e (M-001.11):** at reference, 1.5 steps (4.95 s) is below t\* 2.4 (4.99 s): the step floor never binds.
  Suggest stating one floor.
- **Q-NEW-f (M-001.6 / .12 inputs):** `c` and F_brake,max are not in `gait_log@v1`; registry holds c = 0.05 and
  a_ref = 0.30 g (assumed); suggest `gait_log@v1.1` header fields `c_mech_cost`, `F_act_max_N` (the tool already reads
  an optional `F_act_max_N`).
- **Q-NEW-g (M-004 yaw vs translation):** R-002's table implies no single dither anchoring passes both; renderer and
  calibration question, tool implements as written.
- **Q-NEW-h (M-004 C_px):** C_px uses the M-003 b interleaved definition; R-002's script used a simpler 4-neighbour
  mask. Confirm.
- **Q-NEW-i (gait_log step index):** "n starting at 0" vs logs cut from a run: tool accepts any start, requires
  contiguity.
- **Q-NEW-j (M-002 / M-004 boundary pairs on discrete statistics):** see SPEC_READINGS P4.

- **Q-NEW-k (M-001.12, fix cycle 2 ruling):** R-001's floor "3.1 s = v / (0.30 g)" is a time to zero while the
  measurement stops at < 0.3 m/s; the tool now uses the time to the same end speed, (v - 0.3) / a_ref (orchestrator
  ruling). Suggest R-001 state the end speed of both. With constant deceleration M-001.12 then cannot fail without
  M-001.4 unless an actuator limit binds.
- **Q-NEW-l (M-003 c2, eval-style observation):** the signed reading passes haze targets whose contrast inverts and
  grows with distance (negative dL\* growing in magnitude). The tool keeps the signed gate as written and reports the
  absolute-value reading beside it; R-002 should say which is meant.
- **Q-NEW-m (minimum evidence):** R-001 / R-002 do not define per-capture minimum evidence; the tool requires >= 1
  contact per foot per capture, >= 3 steady strides in walk and curve captures, an evaluated frame per profile, and
  >= 1 % dithered pixels for C_px (assumed). Confirm.
