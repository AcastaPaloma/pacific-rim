## Step 2 done: fault systems, rupture, emergence point
- Decision (orchestrator, applied): a rupture runs on a fault SYSTEM = all sections with the same `fault_name` chained along strike (`FaultTraceSet.Systems`, `FaultSystem`). Chain ends within `MaxBridgeGapM = 5000` (Assumed) are bridged; bridged segments are flagged (`Bridge[i]`), carry zero slip and their end vertices are never emergence vertices (`TouchesBridge`). Components beyond the bridge limit are dropped (`UnchainedChains/Length`). `FaultId` = FNV-1a of the trimmed fault name (`HashName`); `SectionIdx` = index (ordinal section list `Sections`) of the section containing the hypocentre vertex. Golden Gate fault is its own system. Section-level traces (`Traces`) are kept.
- Real data (km, polyline length incl. bridges / mapped): San Andreas fault zone 189.0 / 140.6 (sections North Coast, Peninsula, San Francisco, Santa Cruz Mountains; 69 bridges; 101 unchained chains = 276 km of branches dropped); Hayward fault zone 127.9 / 94.7; Golden Gate fault 17.8; Calaveras 236.4; San Gregorio-Hosgri 186.0. Default Mw 7.2 needs SRL 60.0 km: fits San Andreas (max Mw by length would be 7.8) and Hayward; Golden Gate shortens to Mw MwFromSrlKm(17.8) ~ 6.6.
- `RuptureSolver.Solve`: SRL from Mw (or `SrlKmOverride`); if the system is shorter, Mw is reduced (never stretched, `ShortenedToSystem`); vertex range = nearest vertices to arc position (hypo vertex arc +- SRL/2), shifted inside at the ends, always contains the hypocentre vertex; reported SrlKm = arc length of the range (within one vertex spacing of the target); `EndS` = max side length / speed (bilateral); slip = (1-u^2)^p elliptical taper times seeded smooth variation (+-15 %, Assumed), peak = MD, p solved so the arc-weighted mean (bridges zero) = AD (within 1 %; if AD/MD is above what the flattest shape reaches, i.e. small Mw, the flattest shape is used). All range vertices are polyline vertices (M-053 distance 0). `SlipProfile` is regenerable from (system, range, MdM, AdM, seed).
- `RuptureSolver.ChooseEmergence`: nearest vertex in the range to the target district reference (`DistrictRefs`: GG and SoMa points + `TargetGG`; points not boundaries, Assumed), not touching a bridge; time = EndS + 10 + 5 s; `HeightM` is emitted as 0 (not looked up).
- `QuakeSequence.Run(scenario, districts, sink, originTimeS)` emits QuakeBegan, FaultRupture, EmergencePoint in order, once per EventId (repeat returns null, unknown FaultId returns null with nothing emitted). Sink is `ISeismicEventSink.Publish<T>(T) where T : unmanaged, IEvent`.
