# Game.Composition (T-039)

The game's composition root. The only assembly that references every module's runtime; modules never reference it.

- `GameComposition.Install(registry, flags, errors, inputs)` installs, in order: Geo (`world.geo.enabled`, which also gates the baked Golden Gate Bridge `landmarks` layer, loaded with the tile set), Destruction (`destruction.enabled`; with a `SaveSystem` supplied it also registers `DestructionSaveParticipant` via `DestructionSaveInstaller`, result `DestructionSave`), Seismic (`seismic.enabled`, needs `GameCompositionInputs.Faults`), the Destruction/Seismic shaking bridge (both flags), and the scripted kaiju brain factory (`kaiju.scriptedBrain`). Every flag defaults off, so the committed config installs nothing.
- `GameCompositionBoot` runs it once per Play session from `CoreRuntime.Booted` (added to Game.Core.Unity).
- `NetCoopInstaller` (T-030c): with `net.coop` AND `net.seatBridge` on and `GameCompositionInputs.Net` set, creates the host session + `HostSeatPump` or the client session + `ClientSeatLink` and registers a `NetCoopHandle` (`AttachHostSeat`/`AttachClientSeat` add a `MechSeatBehaviour` to a GameObject). Missing inputs are reported (ConfigMissing), not installed.
- `PlaceholderInstaller` (T-030c): with `units.placeholderBody` on, registers `PlaceholderBodyFactory` (`Create(go, id, seat)` adds the TEMPORARY `PlaceholderBodyBehaviour` and wires the seat's intent frames to it).
- `CombatInstaller` (T-040): with `combat.cannon` and/or `combat.melee` on, registers `CombatHandle` (`Mount(PlaceholderBody, ...)` mounts the enabled weapons through `PlaceholderWeaponMount`; the host calls `Step(dt)`). Missing `ICombatTargetQuery` is reported and an empty world is used; a missing `IEntityHealth` gets a `LinearEntityHealth`.
- `MetaInstaller` (T-122): with `meta.economy` (and, each needing it, `meta.salvage`, `meta.permadeath`, `meta.refit`) on and `GameCompositionInputs.Meta` set (`MetaInputs.FromDirectory(Config root)`; the Play boot supplies `Assets/Game/Config` when a meta flag is on and nothing else was given), loads `economy_prices@v1`, `salvage_yields@v1`, `parts@v1`, `chassis@v1`, installs the four services, registers `economy@v1`, `salvage@v1`, `roster@v1`, `refit@v1` with the `SaveSystem`, registers an `EntityIdAllocator` (shared with Roster), `IAssetValueProvider` (`PriceTableAssetValues`: fixed assets from the price table, buildings from `MetaInputs.Buildings` via `BuildingAssetInfo.From(BuildingId, BuildingAttributes)`; airport and rail rows still open, R-104 Q-NEW-c), `ClassPricing` built from the price table, `HangarRefitGate` (refit only in the Hangar phase, flyable mech of that slot; no hangar installed = every refit refused, reported) and `MetaFightEndBridge`. Result `GameCompositionResult.Meta`. Missing prerequisites, files or malformed data are reported (ConfigMissing / ConfigMalformed), never thrown. All off = nothing read, nothing registered.
- `MetaFightEndBridge` (T-122): the fight-end entry point when the meta layer is on. `OnFightEnd(record, step, strain, location)` = `IRosterService.OnFightEnd` (permadeath, floor chassis), then `IHangarService.EnterHangar(record)` for a survivor (a lost mech's record is not entered: the slot's next mech brings its own), `ISalvageService.Claim` of the wreck for a lost mech (parts of its registered build split by price class, else the chassis composition of the price table; absorbed energy per part 0 until the body record carries it; fall energy g x CoM height of the build, else 392 J/kg), and Refit registration of a granted floor chassis. `CreateMech` creates the roster mech and registers its build under one spec hash; `ApplyRefit` (or any `IRefitService.Apply`, through `RefitApplied`) carries the new hash to the roster with `IRosterService.SetSpecHash`. Record part ids are matched to chassis slot names; until T-005 fixes the body's part ids a slot without a record part takes the record's mean integrity.
- Scene wiring (which mech, which transport) is the caller's. Tile loading and `DistrictRefs` come from the caller through `GameCompositionInputs`.
- Tests: `Tests/EditMode` (Unity EditMode only: the assembly references the Unity adapters).

## Pack and emergence (T-113/T-114 follow-ups)
- `PackInstaller` (flag `ai.pack`, needs the scripted brain factory): registers `PackDirectory` and `PackBrainFactory` (BrainId `pack@1`) under their own types, the `IKaijuBrainFactory` slot stays with `scripted@1`. `PackHandle.Species` = `SpeciesRole` per SpeciesId from the `IKaijuSpeciesCatalog` if registered (`KaijuSpeciesRoles.From`: reach = longest attack, standoff = 7 x reach, fits = spec role affinities, HpRel = R-103 0.2 class weight), else the R-103 defaults.
- `EmergenceInstaller` (flag `emergence.enabled`, needs the Seismic `QuakeDirector`): subscribes `EmergenceDirector` through `SeismicTraceSource`; targets from `GameCompositionInputs.EmergenceTargets`. Result fields `GameCompositionResult.Pack` / `.Emergence`. Tests: `PackCompositionTests` (dotnet + EditMode).
