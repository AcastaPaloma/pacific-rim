Rig: mech from mech_frame_balanced.json + body_tuning.json, free base, no ground, colliders off, gravity 0 unless stated. Raw dumps/logs in the scratch dir (not committed). `DumpEngineData` is an [Explicit] tool that writes the raw engine data to $PROBE_DUMP for offline fitting.
Why 9.4c-1 failed to fit: it re-used ONE rig for many experiments; SetPose/teleport leaves state behind (link speeds grew about 5x per experiment, up to 400 m/s). Every experiment now runs on a fresh rig.
SETTLED (hard asserts, green):
- Sign/DOF mapping (hip = a + th, knee = a - b, ankle = b + f; Sign -1 hip, +1 knee, +1 ankle), 90 x 31 Jacobian dimensions (unchanged from 9.4c-1).
- Jacobian layout. Rows: block of link i starts at EngineLink(i).index*6 (not link order): 3 linear = velocity of the link COM (world), 3 angular (world). Columns = the engine reduced coordinates = GetJointVelocities list = GetDofStartIndices order: 0..2 root COM linear (world), 3..5 root angular (world, about the root COM); joint slot = start[index] + compact slot. With the full engine vector J qdot reproduces all link velocities to 1e-5 (tolerance 3e-3), 3 seeds. ArticulatedBody mapping (ModelColumnOfDof, ModelBaseColumn, GetBodyJacobian incl. sign flips) was already right; the doc comments now state the layout.
- Mass matrix: M = sum J^T diag(m, I_world) J (SI, anatomical) reproduces the measured response to a single joint torque (gravity 0, torque scaled to ~0.004 rad/s after one step): for the 19 DOFs of fully active joints the diagonal (M a)[d]/tau is 1 +- 7e-5 (TolMass 1e-3) and all base/active rows balance to 1e-3 (4e-3). The engine references are unusable: DofTorqueForAcceleration(d,1) = acceleration x 1e5 (ignores inertia; left untouched, imp_ff_accel = 1.0 in walk_tuning), GetJointForcesForAcceleration is a one-body call.
- Bias: GetJointGravityForces with a floating base is the FREE-FALL joint force (entries ~1e-5 of the weight torques, base entries 0), so it cannot be h. GetBiasForce now builds gravity from the Jacobian: h = -Q_g = g sum m_l J_lin,y (h[base y] = +weight exactly, a_base_y = -9.81), plus the engine Coriolis list (fixed base: engine gravity list). Free-fall test M a + h = 0 on base + active rows: 1.3e-7 (TolBias 1e-3). Sign convention: M qdd + h = S tau + J^T f.
OPEN (documented, not loosened):
- Ankle (spherical joint with one locked axis): the lock is soft. A velocity on slot 0/1 leaks 3-7 % into the inert slot, so J qdot over the ACTIVE DOFs only has eLin 9e-4..3.3e-3, eAng 7e-3..3.5e-2 (logged); and the ankle rows of M a = tau fail: diag 0.9928 / 1.0008 / 0.9879 / 0.9692, residual up to 4.4e-2 |tau| (`..._LockedAxisJoints_KnownGap`, [Explicit], red when run). The QP should either carry the inert slot as a column with qdd = 0 and drop its row, or keep the ankle rows loose.
- Engine Coriolis list (GetJointCoriolisCentrifugalForces): zero at rest, scale not verified under motion; its base entries are 0 like the gravity list.
