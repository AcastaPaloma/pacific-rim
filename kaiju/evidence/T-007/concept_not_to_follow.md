explorations. The greybox and `DESIGN_NOTE.md` set the design. This list says, file by file, which parts of
each image must not be copied by any later art task. The concept files are not changed here; they belong to Phase A.
Plate-to-segment grouping is the table in `DESIGN_NOTE.md` ("Plate-to-segment plan"), not any image.
