## 0. Summary
- 6 states: Idle, Approach, Flank, Charge, Retreat, plus Withdrawn (terminal Idle). Target switch is a transition rule evaluated in every combat state, not a state.
- Everything is expressible as intents: desired heading, speed fraction, target id, action. Flank is a heading toward a brain-computed waypoint; no gait, foot or physics access.
- M-007@v1: five behaviour clauses now (flank commit rate, focus-fire excess, switch thrash, information fairness, panel) and one deferred clause (win rate, waits for a trained policy).
- M-058: brain tick cost as a share of the M-008 host budget; threshold p99 frame cost <= 2 % of the host simulation budget, 0 B steady-state allocation.

## 1. Behaviour spec (one species, 80 m / 10,000 t)
### 1.1 Design basis

- Two-layer split (F-021): brain decides *what and where*, motor layer (blocked, Track 3 area) carries it out. The brain never sees feet, gait phase or physics.
- Pack coordination from observation only, no hidden channel: each kaiju reads allies' public state (position, state, target id). This matches the finding that wolf-pack tracking, pursuit and encirclement emerge from two decentralised rules per agent (approach prey to a safe distance, then move away from nearby packmates) with no signalling or hierarchy [1].
- Role asymmetry: in lion group hunts (486 coordinated hunts) some animals circle the quarry ("wings") while others wait for it to move toward them ("centres"), and success was higher when animals took their preferred stalking positions [2]. The scripted brain uses a deterministic wing/centre split by sorted `EntityId`.
- Game-AI precedent: a small explicit state machine plus a planner is an accepted way to ship convincing coordinated enemies (F.E.A.R. used 3 states and an A* planner) [3]. Our scripted baseline is a plain state machine (cheap, testable, deterministic); the RL policy later replaces it.
- Caveat on the "flank" claim [3]: a write-up found F.E.A.R.'s flanking was largely cover-to-cover movement. We therefore measure flanking geometrically from positions (§3) rather than trusting the state name.

### 1.4 States, transitions, and the intent each writes
Intent = (heading, speedFrac, targetId, action); `dir(P)` = bearing toward point P. `action` in {None, Melee}.
| State | Entry | Intent written each tick | Exit (first true wins) |
|---|---|---|---|
| **Idle** | spawn, target lost > 3 s, target dead with none other | heading = current, speedFrac 0, target 0, None | a target visible or remembered -> Approach |
| **Approach** | Idle sees target; Flank/Charge reset | heading = dir(target.pos), speedFrac 0.6 (centre role or solo: 0.6; wing: 0.8), target = current | d <= d_s: solo -> Charge; wing with allies -> hold at d_s (speedFrac 0) until the pack is assembled (rev 2 gate) then Flank, or Charge if an ally charges; centre -> hold at d_s (speedFrac 0) until an ally enters Charge, or 6 s pass with no ally in Flank and the pack assembled (cap 90 s), then Charge. hp < 0.35 -> Retreat. target lost -> Idle |
| **Flank** (wings only) | Approach at d_s with >= 1 live ally | waypoint W = target.pos + d_s * unit(angle(bearing_to_pack_centroid) + side * theta_f), side = +1/-1 alternating by sorted `EntityId`; heading = dir(W), speedFrac 0.8, target = current | bearing error <= 15 deg and engaged spread >= 90 deg, or the arc-derived timeout (1.3, set at entry), or an ally in Charge -> Charge. hp < 0.35 -> Retreat |
| **Charge** | slot reached or synchronised | heading = dir(target.pos), speedFrac 1.0, target = current, action = Melee when d <= r_m | no contact within 8 s -> Approach; target dead -> retarget or Idle; hp < 0.35 -> Retreat |
| **Retreat** | hp < 0.35 | heading = away from nearest visible threat, speedFrac 0.7, target 0, None | d_nearest > 600 m for >= 10 s -> Withdrawn (Idle, never re-engages in v1) |

Solo kaiju (no live ally) skip Flank. The Withdrawn state is Idle with a `withdrawn` flag; it keeps the state count at 6 and avoids a hp-regeneration rule the harness does not have (Q-NEW-e).

### 1.5 Target selection and switching
Score for candidate T (higher is better), evaluated every tick in Approach, Flank and Charge:

`score = 1.0 * (1 - d/R_s) + 0.8 * (1 - hpFrac_T) + 0.6 * facing_me_T + 0.5 * allies_on_T / max(1, allies)`

- `facing_me_T` = 1 if T's heading is within 45 deg of the bearing to me, else 0 (threat term).
- The last term is the focus bonus; it makes pack focus fire arise without a central controller (cf. [1]).
- Weights are *Assumed*; they are config values, tuned in T-032 by the C2/C3 clauses below.
- **Voluntary switch** only if best score > 1.25 x current score and >= 4 s since the last switch. **Forced switch** when the target dies or is lost > 3 s (not counted as voluntary in C3).

## 2. `IKaijuBrain` (shared with the F-021 RL policy)
### 2.1 Interface (pure C#, assembly `Kaiju.Brain`, layer L2, depends on Core only; sketch)

```csharp
public interface IKaijuBrain {
    int ContractVersion { get; }                 // 1
    void Reset(ulong seed, in BrainConfig cfg);  // seed from run seed; Core has no unseeded randomness
    void Decide(in BrainObservation obs, ref BrainIntent intent); // no allocation, no wall clock
}
```

`Decide` is a pure function of (obs, brain state, seed). Same seed and same observation stream give byte-identical intents (needed for replay and for the brain_log golden test).

### 2.2 Observation (blittable structs; fixed-size arrays via fixed capacity N)
| Field | Type | Notes |
|---|---|---|
| `Step`, `TimeSeconds` | long, double | from Core Clock (contract 1) |
| `Self.Id` | `EntityId` | `ent:<u64>` |
| `Self.PackId` | uint | pack membership, 0 = solo |
| `Self.Pos`, `Self.HeadingRad`, `Self.Speed` | float2, float, float | world metres, 2D in the harness |
| `Self.HpFrac` | float | 0..1 |
| `Self.State`, `Self.StateAgeSteps` | byte, int | brain's own state, fed back |
| `Self.Cooldowns` | float | melee cooldown seconds |
| `Targets[0..NT)` | id, pos, heading, speed, hpFrac, alive, visible, memoryAge (s) | NT <= 8 (mechs/others), sorted by `EntityId`; only visible or remembered entries |
| `Allies[0..NA)` | id, pos, heading, hpFrac, alive, state, targetId, role | NA <= 7, public state only, sorted by `EntityId` |
| `Config`-derived | none per tick | passed once to `Reset` |

Ordering by `EntityId` ordinal is mandatory (determinism rule in Core). The RL policy receives the same struct, flattened by a fixed encoder (T-032 owns the encoder; not specified here).

### 2.3 Intent and tick rate
| Field | Type | Meaning |
|---|---|---|
| `DesiredHeadingRad` | float | world-frame heading the body should face and move along |
| `SpeedFrac` | float 0..1 | fraction of max speed in that heading |
| `TargetId` | `EntityId` (0 = none) | explicit target (used for log and Melee) |
| `Action` | byte enum {None, Melee} | |
| `State`, `ReasonCode` | byte, byte | diagnostics, written to brain_log; not consumed by the seat |

- Field names are *Assumed*; map to whatever the Control seat/arbiter exposes (Q-NEW-a). The brain writes intents through the arbiter like any other source.
- Tick rate: brain decides every `brainPeriodSteps = round(0.2 s / StepSeconds)` fixed steps (12 at R-005's 1/60 s, 10 at Core's 0.02 s default; *Assumed* 5 Hz). Between decisions the seat holds the last intent. 0.2 s is a human-reaction-order delay (*Assumed*; no primary source retrieved), and it makes a 10,000 t body that cannot change course in under seconds look deliberate rather than twitchy. Stagger kaiju phases by `EntityId mod brainPeriodSteps` so costs do not spike on one frame.
- Feature flag `kaiju.scriptedBrain`, ships `false` (Core flag rule).

## 3. Pack primitives (exact definitions from logged positions)
Notation. Decision tick k at time t_k; kaiju i has position p_i(k), target T_i(k) (0 if none), alive a_i(k). Target position q_T(k) comes from the `target_sample` rows (§4).
**Engaged**: a_i = 1, T_i != 0 and |p_i - q_{T_i}| <= D_eng = 400 m. For target T: G_T(k) = {i engaged with T_i = T}.

### 3.1 Flank rate
- Bearing of kaiju i at its target: beta_i(k) = atan2(p_i - q_T) in [0, 360) deg.
- Spread S_T(k) = 360 deg minus the largest circular gap between sorted bearings of G_T(k) (the minimal arc containing all of them). Defined when |G_T| >= 2, else undefined.
- **Flanked(T,k)** iff |G_T(k)| >= 2 and S_T(k) >= 90 deg (*Assumed*; two kaiju on opposite quadrants, comparable to the encirclement geometry of [1], which reports no angular threshold).
- **Commit event** c: first tick at which any member of the pack enters Charge toward T within an engagement of T (a Charge entry with no pack member in Charge toward T in the previous 8 s). **Flank commit rate** `FR_commit = (#commit events with Flanked evaluated at that tick) / (#commit events with |G_T| >= 2)`.
- Secondary (informational): `FR_time = sum_k Flanked(k)*dt / sum_k [|G_T(k)| >= 2]*dt`.
- Null control: the same scenario set run with a `DirectCharge` brain (state Approach then Charge, no Flank, no wing offset); `FR_commit_null` is measured, not assumed.

### 3.2 Focus fire
- `FF(k) = max_T |{i alive : T_i(k)=T}| / |{i alive : T_i(k) != 0}|`, evaluated at ticks with >= 2 kaiju with a target and >= 2 live visible targets (otherwise focus is trivially 1).
- Chance level: `FF_chance(n, m)` = E[max bin count]/n when n kaiju pick uniformly among m targets (exact multinomial enumeration in the tool; n=3, m=2 gives 0.75; n=4, m=2 gives 0.6875: E[max]=2.75 over Binomial(4,1/2); the 0.8125 first printed here was an arithmetic slip, fixed in rev 2).
- **Focus excess** `FE = (mean FF - mean FF_chance) / (1 - mean FF_chance)` (0 = random assignment, 1 = always all on one target).
- Damage companion (informational): share of kaiju melee damage landed on the single most-damaged target per 30 s window.

### 3.3 Target switching
- **Voluntary switch**: T_i(k) != T_i(k-1), both nonzero, and `reason = VoluntaryRetarget` (not target death or loss).
- **Switch rate** = voluntary switches per kaiju-minute engaged.
- **Thrash**: a voluntary switch that returns to the target held before the previous switch within 4 s (A -> B -> A). **Thrash fraction** = thrash switches / voluntary switches (0 if none).

### 3.4 Information fairness (the "not cheap" check)
- **Leak**: tick where T_i(k) != 0 and the target row has `visible = 0` and `memory_age > 3 s` (target neither visible nor remembered). The brain must have 0 leaks.

## 5. Metric specs
### `M-007@v1` Kaiju look intelligent (behaviour clauses; win-rate clause deferred)

- **Definition.** On the 2D kinematic harness (no kaiju locomotion), a scripted pack of 3 kaiju (80 m, 10,000 t) fights 2 slow decoy mechs (1.5 m/s waypoint walkers, no flee) on an open 4 km x 4 km field, N = 100 seeded runs of **300 s** (rev 2: 90 s cannot fit a 600-900 m approach at 5.5 m/s plus assembly and a ~40 s flank arc; harness `HarnessScenario.M007(seed, directCharge)`). Clauses are evaluated from `brain_log@v1` by the T-033 tool in `Tools/Metrics`.
- **Procedure.** Run `scripted@1` and the `DirectCharge` control on the same 100 seeds; compute §3 primitives per run, pool by engagement; report median and 95 % bootstrap interval across runs.
- **Clauses and thresholds** (all *Assumed*, pending founder calibration, unless noted):
| Clause | Measure | Pass |
|---|---|---|
| C1 Flank | `FR_commit` (§3.1) | >= 0.60 and >= 2 x `FR_commit_null` |
| C2 Focus | `FE` (§3.2) | >= 0.50 |
| C3 Switching | thrash fraction (§3.3); voluntary switch rate | thrash <= 0.10; rate <= 3 per kaiju-minute |
| C4 Fairness | leaks (§3.4) | 0 |
| C5 Panel | >= 12 human raters watch 6 clips each (3 scripted, 3 control, blinded); 7-point items "smart" and "cheap" | median "smart" >= 5 and median "cheap" <= 3 |
| C6 Win rate (deferred, waits for a policy) | policy pack vs scripted pack, 200 paired seeds, sides swapped | win rate >= 0.55 with Wilson 95 % lower bound > 0.50 |

- **Source / rationale.** Wolf-pack encirclement, tracking and pursuit emerge from approach-then-spread rules [1]; lion role asymmetry wings vs centres and higher success from preferred positions [2]; flank claims must be checked geometrically, not by state name [3]. The panel clause follows the human-judge format of the BotPrize Turing test for game bots, where human judges rate how human-like opponents are [4]. The thresholds themselves are design targets, not literature values.
- **Open.** C5 rater count, rubric wording and scale are the founder's (Q-NEW-c). C6 cannot run until F-021 has a trained policy; until then M-007@v1 passes on C1-C5.

### `M-058@v1` Brain tick cost (share of the M-008 host budget)
- **Definition.** `share = brain_ms_per_frame / B_host`, where `brain_ms_per_frame` = total `IKaijuBrain.Decide` wall time (Stopwatch ticks, no allocation in the probe) summed over all kaiju in one rendered frame, and `B_host` = the host simulation budget of M-008.
