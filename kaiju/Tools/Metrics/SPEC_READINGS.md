# Spec readings and defects (T-002, `kaiju_metrics` 1.0.0)

The research specs are implemented as written (`M-001@v1`, `M-002@v1` in `research/R-001.md` §9; `M-003@v1`, `M-004@v1`
in `research/R-002.md` §4-§5). Where a spec is silent or ambiguous the tool uses the reading below. **R** = reading fixed
by the reconciled spec `expectations/T-002.md`; **L** = most literal reading chosen by the implementer; **X** = tool-side
contract extension; **D** = defect against the spec, reported to the scribe (`tasks/T-002.impl.md`). No threshold was
changed; every number is in `registry/`.

## Gait (M-001, M-002)
| # | Topic | Reading | Kind |
|---|---|---|---|
| G1 | Steps, strides | A step is half a stride; step duration = header `T_stride_nom_s` / 2. Stride = same-foot `contact_begin` to `contact_begin`, from the tool's F_on / F_off hysteresis on `fn` (not the emitter's events). Stride period = median over steady strides, pooled over feet. | R |
| G2 | t\* | t\* = t / sqrt(l / g) (R-001 §4 defines it; expect-A §4.4's "units of T_nom/2" is not used). | L |
| G3 | Steady strides | `cmd_speed` identical over two consecutive strides of a foot and abs(dv_bar) < 0.02 g T of the later stride; both strides of such a pair are steady. ">= 3 strides of steady state" = >= 3 steady strides on every foot, else the capture's band / period / duty parts are NOT_RUN. | L |
| G4 | M-001.1 scope | Band [0.10, 0.30] on the mean steady v_bar of every walk capture and of any capture with >= 3 steady strides; cruise check (+-0.03 of header `fr_cruise_nom`) on `walk_fr020`; "never > 0.35" on every stride of every capture. | L |
| G5 | M-001.3 | Duty = stance of the contact opening the stride / stride time, mean per foot over steady strides; each foot judged; double support 2 beta - 1 reported. | R |
| G6 | Fore-aft / lateral | Projections of the smoothed CoM acceleration on the logged root heading (unwrapped yaw): forward (sin psi, 0, cos psi), right (cos psi, 0, -sin psi). Window = nearest odd sample count to 0.05 T_nom / dt (17 at reference), truncated at the log ends. Unsmoothed peaks are printed beside smoothed ones. | R |
| G7 | Yaw signals | Yaw rate = d(unwrapped yaw)/dt then the same filter; yaw acceleration = the filter on the central difference of the unfiltered yaw rate. The logged `yaw_rate` is only cross-checked (warning `YAW_RATE_INCONSISTENT`). | L |
| G8 | Header scaling | M-001.5 and M-001.9 use 0.085 g scaled by the header (W_f/2)/h relative to the reference ratio (R-001 §2 tipping formula, procedure 4); M-001.7 scales by sqrt(42.4/l) (as written); M-001.8 by 42.4/l (R-001 §3 "angular acceleration scales as g/l"; the table is silent). | L, D |
| G9 | M-001.6 | Command = first rise of `cmd_speed`; v_cruise = sqrt(fr_cruise_nom g l); t90 = first sample with horizontal speed >= 0.9 v_cruise; net = dv / dt. Power half: smoothed a_fore <= (P - c m g v)/(m v) at every sample with v > 0; P = header `reactor_power_W`, c = 0.05 in the registry (assumed_pending_calibration). | R |
| G10 | M-001.9 | v_bar(t) = centred moving average of horizontal speed over one T_nom; judged as abs(yaw rate) * v_bar <= a_lat (equivalent to yaw rate <= a_lat / v_bar). | L |
| G11 | M-001.11 / .12 | Stop time = first drop of `cmd_speed` to the first sample with speed < 0.3 m/s. Emergency floor (fix cycle 2, orchestrator ruling on DEF-T002-feel-1: like with like) = max((v_cruise - 0.3) / a_ref, m (v0 - 0.3) / F_brake,max): the time to reach the same end speed (< 0.3 m/s) the measurement uses; a_ref = 0.30 g (registry), F_brake,max = min(a_ref m g, optional header `F_act_max_N`). R-001's "3.1 s" is v/(0.30 g), a time to zero: comparing it with a time to 0.3 m/s failed a stop at exactly 0.30 g. Consequence: with constant deceleration M-001.12 fails only together with M-001.4 unless an actuator limit binds. "Grows with m across >= 2 mass variants" is PENDING and non-gating until variant logs exist (reported in `info.mass_variants`). | R |
| G21 | Per-capture minimum evidence (fix cycle 2, DEF-T002-arch-1) | Every capture must have >= 1 usable contact on every foot (`min_contacts_per_foot`, registry v1.1); a capture without it makes M-002.1 / M-002.4 NOT_RUN for that capture and is listed in `coverage.missing` (INCOMPLETE); M-001 lists it too. `steady_captures` (walk_fr010/020/030, curve) must each show >= 3 steady strides; a curve that never exceeds 0.5 v_cruise makes M-001.9 NOT_RUN. Pooled counts never hide an empty capture. | R, L |
| G12 | M-001.11 bounds | At reference 1.5 steps = 4.95 s = t\* 2.38 < 2.4: the t\* floor is the binding lower bound, the 1.5-step floor never decides. | D |
| G13 | M-001.13 | Blind raters only; >= 3 raters with an `overall` score; median overall >= 8; each scenario (cruise, start, stop, turn90_inplace, curve) median > 6. No file or too few raters = PENDING (metric INCOMPLETE, `headless_verdict` still reported). Ratings format `panel_ratings@v1` is defined by the tool (`kaiju_metrics/ratings.py`). | R, X |
| G14 | M-002 contacts | Spec hysteresis on `fn` with 0.03 / 0.01 m g (header mass), starting off; contacts cut by the log window are kept and tagged `truncated_start` / `truncated_end`; scuffs (< 0.1 T_nom) tagged, not exempt; exclusion when `ext_f` > 0.05 m g at any sample. | R |
| G15 | M-002 slip | n_bar_c = normalised sum of fn * cn over the contact (world up if no `cn` was logged); heights measured along n_bar_c above the lowest of the five sole points; anchor = first loaded sample of each point. | L |
| G16 | M-002.3 | Gaps in `n` and float32-quantised positions are contract errors (INVALID_INPUT, an emitter fault, never a slip failure), so M-002.3 can only fail on `fixed_dt_s` > 0.02 s. float32 detection: median of abs(x - f32(x)) / ulp32 < 0.05 over >= 100 non-dyadic coordinates with abs(x) >= 16 m. | R, L |
| G17 | M-002.4 | Agreement of the emitter flag with the spec hysteresis over all feet x steps; no grace step (expect-B §4.7 suggested one; not adopted). | L |
| G18 | M-002.5 | A stomp with an external force > 0.05 m g makes M-002.5 FAIL (as written: locomotion captures include stomp). | L |
| G19 | gait_log validation | Beyond R-001 §8: g must be 9.81, physics_hz x fixed_dt = 1, unit quaternions and normals, yaw in (-pi, pi], com_v must be the derivative of com_p (catches km/h, cm), `n` contiguous but may start above 0 (cut logs). Any failure = INVALID_INPUT (R-001's `INVALID_LOG`). | L |
| G20 | Normalisers | Header values that differ by > 1 % from the registry reference unit are flagged `NON_REFERENCE_NORMALISERS` (warning); header F_on / F_off different from the spec values are flagged with the contact-count effect; the tool always uses the spec values. | R |

| S16 | M-004 guards | Speed check from the continuous sidecar poses (`position_local_m`, `yaw_pitch_roll_deg`) over the whole sequence: translation in px at 600 m, yaw in px at screen centre; > 10 % from the declared speed = INVALID_INPUT; a static sequence whose camera moves > 0.001 px/frame = INVALID_INPUT. Frozen = every frame identical to frame 0 while the camera moves >= 1 px; blank = one index over all non-animated pixels; both INVALID_INPUT. | R, L |
| S17 | M-004 coverage | 3 profiles x 2 viewpoints x the six classes; viewpoint = sequence.json `viewpoint` (extension, default "default"); `--profiles` / `--viewpoints` narrow the requirement. | X |

| S21 | Conventions (DEF-T002-arch-4) | `conventions.up` must start with "+Y", `forward` with "+Z", `pixel_origin` with "top-left" (the tool's projection), as handedness "left". | L |
| S22 | Integrity (DEF-T002-arch-2) | The validator checks every PNG completely without decoding pixels: every chunk complete with a matching CRC-32, IHDR first, an IDAT, IEND last. A file the decoder still rejects is INVALID_INPUT (exit 2) in every metric. | L |
| S19 | Capture validation | `output_wh` must equal `internal_wh` x `integer_scale`; depth must be png16_log (EXR is optional in the contract and unsupported in tool v1: INVALID_INPUT with that message); TAA / motion blur / bloom flags true = INVALID_INPUT. | L |

## Reports and process
| # | Topic | Reading | Kind |
|---|---|---|---|
| P1 | Verdicts | PASS / FAIL / INVALID_INPUT / INCOMPLETE, exit 0 / 1 / 2 / 3; 4 = tool error (never a verdict). A gating FAIL wins over missing evidence. | R |
| P2 | Draft metrics | A registry with `metric_status: draft` reports failures but its verdict is INCOMPLETE with flag `DRAFT_METRIC_CANNOT_FAIL` (orchestrator §4.4). | L |
| P3 | Revisions | Spec stays `@v1`; a calibration produces registry revision v1.N in a new file `M-00x@v1.N.yaml`; the default is the newest revision; reports name revision and SHA-256; `rescore` finds the old revision by hash. | R |
| P4 | Boundary pairs | For share thresholds near 1 (0.99, 0.995) the pair is taken on the complement (failing share at 98 % / 102 %); discrete statistics (frame share, Spearman over bands, level and hue counts, excluded-contact count) use the nearest achievable values on each side. | L |
| P5 | Baseline | The R-002 de-noising, masks (`panels.json` boxes and exclusions, ref_06A alpha eroded 4 px) and per-panel palettes / profiles are reimplemented; inapplicable measures are NOT_APPLICABLE; verdict "NOT_APPLICABLE: not a capture set". | R |
